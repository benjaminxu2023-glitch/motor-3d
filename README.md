# 三相电机 3D 构造与原理

在线演示：https://benjaminxu2023-glitch.github.io/motor-3d/ （适配 iPhone Safari）

## 内容
三相鼠笼异步电机的可交互 3D 模型，可切换为永磁同步转子对比。
- 构造：硅钢片叠压定子铁心与槽、A/B/C 三相分布绕组（X/Y/Z 为回线边，国标黄/绿/红）、端部、气隙、鼠笼导条+端环 / N·S 永磁体、转轴、机壳剖切、爆炸视图、标签。
- 原理：三相电流波形与时间光标、⊙/⊗ 电流方向（颜色深浅=大小）、恒幅旋转合成磁场与气隙磁场分布、滑差与导条感应电流、永磁转子负载角 δ、交换两相反转。

## 操作
单指拖动旋转，双指缩放，双击复位。底部按 7 步引导：结构总览 → 定子与线圈排布 → 三相电流 → 合成旋转磁场 → 转子为什么会转（滑差）→ 永磁转子对比 → 反转：交换两相。
